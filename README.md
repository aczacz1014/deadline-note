# 마감노트

대학생의 과제와 팀 프로젝트 마감, 진행 상태, 우선순위를 한곳에서 관리하는 개인용 웹 앱입니다.

- 웹 앱: https://deadline-note-campus.wigglycream18.chatgpt.site
- 소스코드: https://github.com/aczacz1014/deadline-note

## 주요 기능

- 과제 등록, 조회, 수정, 삭제
- 시작 전 / 진행 중 / 완료 상태 변경과 완료 되돌리기
- 오늘 마감, 지연, D-day 표시와 7일 이내 마감 목록
- 과제명·수업명·메모 검색, 수업·분류 필터, 마감·우선순위·최신순 정렬
- 남은 과제, 오늘 마감, 완료율 대시보드
- localStorage 자동 저장, JSON 백업 내보내기와 불러오기
- 첫 사용 시 가상 예시 과제 추가, 예시만 삭제
- 반응형 화면과 키보드 사용, 입력값·백업 형식 검사

## 실행

배포된 웹 앱을 열면 바로 사용할 수 있습니다. 예시 데이터는 `예시 과제로 둘러보기`로 추가합니다.

로컬 실행에는 정적 HTTP 서버가 필요합니다. HTML을 파일로 직접 여는 대신 프로젝트에서 다음과 같이 실행하세요.

```bash
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. 런타임 패키지 설치나 API 키는 필요하지 않습니다. Node.js가 있다면 다음으로 데이터 처리 테스트를 실행할 수 있습니다.

```bash
npm test
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `dist/index.html` | 대시보드, 입력 폼, 목록, 확인 창 |
| `dist/styles.css` | 화면 디자인과 반응형 레이아웃 |
| `dist/model.js` | 데이터 검증, 마감 계산, 검색·정렬, 저장·백업 |
| `dist/app.js` | 화면 렌더링과 사용자 입력 이벤트 |
| `tests/model.test.mjs` | 저장 유지, 날짜 경계, 검색·정렬, 손상 백업 검증 |
| `docs/development-log.md` | 실제로 발견한 오류와 수정 기록 |

## 데이터와 한계

기록은 **방문자의 현재 브라우저 localStorage**에 저장됩니다. 서버 데이터베이스나 계정을 사용하지 않습니다. 같은 URL을 열어도 방문자 간 데이터는 공유되지 않습니다. 다른 기기나 브라우저에는 자동 동기화되지 않으며, 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다. 백업 파일은 현재 기록 전체를 교체하므로 확인 창에서 교체 여부를 선택합니다.

마감 표시는 앱을 열어 둔 동안 1분마다 갱신되며, 브라우저 푸시 알림은 제공하지 않습니다. 예시 데이터는 가상 기록입니다.

## 배포

배포 대상 폴더는 `dist`입니다. 빌드 단계가 없는 정적 웹 앱이므로 정적 파일 호스팅을 지원하는 서비스에서 배포할 수 있습니다. 현재 배포 설정은 `.openai/hosting.json`에 있습니다. 소스코드와 사용자 과제 데이터는 분리되며, 과제 기록은 저장소에 업로드되지 않습니다.

## 검증

자동 테스트 9개 통과. 브라우저에서 등록, 수정, 완료, 새로고침 유지, 검색, 필터, 삭제, 백업 다운로드를 확인했습니다. 검증 주체와 구체적인 결과는 개발 기록에 정리했습니다.
